klipper-connect runs next to Moonraker and speaks to Prusa Connect the same way PrusaLink does, so a printer running Klipper shows up in Connect like any other Original Prusa. Tested on an MK3S, experimental on the MINI.

What works

Watch

  • Printer state, temperatures, fans, speed and flow
  • Progress, time printing and time left
  • Print history and statistics in Connect
  • Webcam snapshots from crowsnest

Control

  • Start, pause, resume and stop prints
  • Set temperatures, home, move and level the bed
  • Load and unload filament with your macros
  • Send G-code and restart the firmware

Files

  • Browse the gcodes folder, with thumbnails
  • Upload from Connect, and print after upload
  • Delete files and create folders

Klipper extras

  • Loaded material from Spoolman
  • Bed mesh after leveling
  • Several printers on one host, one bridge each
  • Updates from Mainsail or Fluidd's update panel

Not supported yet: binary G-code (.bgcode, so turn it off in PrusaSlicer) and Connect's on-printer dialogs.

Install

On the Raspberry Pi (or other host) that runs Klipper and Moonraker.

  1. Clone and run the installer

    It sets up the service and adds klipper-connect to Moonraker's update manager.

    git clone https://github.com/amd989/klipper-connect.git ~/klipper-connect
cd ~/klipper-connect && ./scripts/install.sh

    Using KIAUH? Copy kiauh/klipper_connect into KIAUH's extensions folder and install it from the Extensions menu. Several printers on one host? See the install options.

  2. Add your serial number

    Set serial_number in ~/printer_data/config/klipper_connect.conf to the CZPX number on the sticker on the back of your printer.

  3. Link it to Prusa Connect

    Open the link it prints, confirm, then start the service.

    ~/klipper-connect-env/bin/klipper-connect register
sudo systemctl start klipper-connect
